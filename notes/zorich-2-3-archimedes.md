## Принцип Архимеда

Для любых `a > 0` и `b > 0` существует `n ∈ ℕ` такое, что `na > b`.

**Доказательство (через супремум).** Пусть множество `E = {na : n ∈ ℕ}` ограничено сверху числом `b`. Тогда существует `s = sup E`. Число `s − a` не является верхней границей `E`, поэтому найдётся `n` с `na > s − a`. Но тогда `(n + 1)a > s`, что противоречит определению `s`. Значит, `E` не ограничено сверху, и нужное `n` существует.

## Наименьший элемент

Если непустое `A ⊆ ℤ` ограничено снизу, то в `A` есть наименьший элемент. Идея: сдвигом перевести `A` в подмножество `ℕ` и применить принцип наименьшего числа.

## Следствие 7°

Для любого `ε > 0` существует `n ∈ ℕ` с `1/n < ε`.

Доказательство: принцип Архимеда при `a = ε`, `b = 1` даёт `nε > 1`, то есть `1/n < ε`.

## Следствие 9° — плотность ℚ

Для любых `a < b` существует `r ∈ ℚ` такое, что `a < r < b`.

1. По следствию 7° выбираем `n ∈ ℕ` с `1/n < b − a`.
2. Множество `{k ∈ ℤ : k/n > a}` непусто и ограничено снизу; берём его наименьший элемент `m`.
3. Из минимальности `m`: `(m − 1)/n ≤ a < m/n = r`.
4. Оценка расстояния: `r = m/n ≤ a + 1/n < a + (b − a) = b`.

Ключ — шаг 3: минимальность `m` даёт не только `r > a`, но и `r − a ≤ 1/n`.

Пример: `a = 1,4`, `b = 2,1`, `n = 2`, `m = 3`, `r = 3/2`.
