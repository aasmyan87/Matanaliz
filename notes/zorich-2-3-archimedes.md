Страницы 79–81. Формулировки сверены по PDF 2026-11-08 (нумерация PDF-страниц совпадает с печатной).

## Что доказывается до принципа (1°–5°)

1°. В любом непустом ограниченном сверху подмножестве `ℕ` есть максимальный элемент (через `sup`).
2°. `ℕ` не ограничено сверху.
3°. В любом непустом ограниченном сверху подмножестве `ℤ` есть максимальный элемент.
4°. В любом непустом ограниченном снизу подмножестве `ℤ` есть минимальный элемент.
5°. `ℤ` не ограничено ни сверху, ни снизу.

## Принцип Архимеда (6°)

Если `h > 0`, то для любого `x ∈ ℝ` существует, и притом единственное, `k ∈ ℤ` такое, что

```
(k − 1)h ≤ x < kh.
```

**Доказательство.** Множество `{n ∈ ℤ : x/h < n}` непусто (так как `ℤ` не ограничено сверху) и ограничено снизу; по 4° в нём есть минимальный элемент `k`. Тогда `(k − 1) ≤ x/h < k`; умножаем на `h > 0`. Единственность следует из единственности минимального элемента.

**Замечание.** Классическая форма «для `a > 0`, `b > 0` существует `n ∈ ℕ`: `na > b`» получается при `h = a`, `x = b`: `(k − 1)a ≤ b < ka`, значит `ka > b`; при этом `k > 0`, так как `b > 0`.

## Пример: h = 0,3, x = 2,0

Кратные `h`: `0; 0,3; 0,6; 0,9; 1,2; 1,5; 1,8; 2,1; …`

Шесть полных шагов дают `1,8 ≤ 2,0`, а седьмой — `2,1 > 2,0`. Значит, `k = 7` и `x ∈ [6h, 7h) = [1,8; 2,1)`.
Остаток: `x − 6h = 0,2 < 0,3 = h`.
Проверка: `(7 − 1)·0,3 = 1,8 ≤ 2,0 < 2,1 = 7·0,3`.

## Следствие 7°

Для любого `ε > 0` существует `n ∈ ℕ` такое, что `0 < 1/n < ε`.

Доказательство: по 6° при `h = ε`, `x = 1` получаем `(k − 1)ε ≤ 1 < kε`, то есть `kε > 1`; из `k > 0` следует `k ∈ ℕ` и `1/k < ε`.

## Следствие 9° — плотность ℚ

Для любых `a, b ∈ ℝ` с `a < b` найдётся `r ∈ ℚ` такое, что `a < r < b`.

**Доказательство (Зорич).**

1. По следствию 7° выбираем `n ∈ ℕ` с `0 < 1/n < b − a`.
2. По принципу Архимеда (6° при `h = 1/n`, `x = a`) находим `m ∈ ℤ`: `(m − 1)/n ≤ a < m/n`.
3. Если бы `m/n ≥ b`, то `(m − 1)/n ≤ a < b ≤ m/n`, откуда `1/n ≥ b − a` — противоречие с `1/n < b − a`. Значит, `m/n < b`.
4. Итак, `r = m/n ∈ ℚ` и `a < r < b`.

Прямая (эквивалентная) запись шага 3: `r = m/n ≤ a + 1/n < a + (b − a) = b`.

Ключ — шаг 2: минимальность `m` даёт не только `m/n > a`, но и `(m − 1)/n ≤ a`, то есть `r − a ≤ 1/n`.

Пример: `a = 1,4`, `b = 2,1`, `n = 2`, `m = 3`, `r = 3/2`.

## Следствие 10°

Для любого `x ∈ ℝ` существует, и притом единственное, `k ∈ ℤ` такое, что `k ≤ x < k + 1`; это `[x]`, целая часть числа `x`.

## Не разобрано

- следствие 8°: если `0 ≤ x` и `x < 1/n` для всех `n ∈ ℕ`, то `x = 0`;
- следствие 10°: целая часть — формулировка известна, разбора ещё не было.
