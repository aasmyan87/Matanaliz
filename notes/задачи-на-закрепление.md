# Генерация задач на закрепление

## Назначение

Этот файл — постоянный банк дополнительных задач для тренировки уже изученных тем. Новые задачи добавляются только по запросу пользователя. Сейчас банк пуст: ожидается тема или список тем.

## Правила ведения банка

- Объединять задачи в группы по общему математическому смыслу.
- Название каждой группы формулировать самостоятельно по содержанию задач.
- Давать каждой задаче сквозной уникальный номер вида `ПЗ-001`, `ПЗ-002`, `ПЗ-003` и далее. Номера не переиспользовать.
- Сохранять вместе с условием проверенный ответ. Если пользователь попросит ответ по номеру, отвечать кратко, не показывая решение, если он отдельно не попросит разбор.
- До отправки сверять каждое условие и ответ. Подбирать задачи на закрепление указанной темы, при необходимости располагая их от более простых к более сложным.
- Сохранять уже выданные задачи и ответы при добавлении новых групп.

Задачи пока не сгенерированы. Первую группу и её название добавить после того, как пользователь укажет тему или пришлёт задачи, на основе которых нужно составить тренировочные.
