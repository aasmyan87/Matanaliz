# Генерация задач на закрепление

## Назначение

Этот файл — постоянный банк дополнительных задач для тренировки уже изученных тем. Новые задачи добавляются только по запросу пользователя.

## Правила ведения банка

- Объединять задачи в группы по общему математическому смыслу.
- Название каждой группы формулировать самостоятельно по содержанию задач.
- Давать каждой задаче сквозной уникальный номер вида `ПЗ-001`, `ПЗ-002`, `ПЗ-003` и далее. Номера не переиспользовать.
- Сохранять вместе с условием проверенный ответ. Если пользователь попросит ответ по номеру, отвечать кратко, не показывая решение, если он отдельно не попросит разбор.
- До отправки сверять каждое условие и ответ. Подбирать задачи на закрепление указанной темы, при необходимости располагая их от более простых к более сложным.
- Сохранять уже выданные задачи и ответы при добавлении новых групп.

## Группы задач

Во всех задачах ниже `ℕ={1,2,3,…}`.

### Группа 1. Верхние грани: граничный выбор и достижение супремума

Первые задачи требуют использовать ограничения на параметры, сравнивать граничные случаи и отличать максимум от недостигаемого супремума.

1. **ПЗ-001.** Найти `sup {(3m+1)/(4n+2) : m,n∈ℕ, m<n}`.
2. **ПЗ-002.** Найти `sup {(m+5)/(2n+3) : m,n∈ℕ, m≤2n}`.
3. **ПЗ-003.** Найти `sup {(m²+12m+1)/(m²+3m+5) : m∈ℕ}`.
4. **ПЗ-004.** Найти `sup {(3m+1)/(2n+2) : m,n∈ℕ, 2m≤3n}`.
5. **ПЗ-005.** Найти `sup {(m+n+3)/(m+2n+1) : m,n∈ℕ, m≤n}`.

### Группа 2. Нижние грани: зазор до инфимума и граничные значения

Здесь нужно доказать нижнюю оценку, исследовать, достигается ли она, и при необходимости подобрать параметры, чтобы приблизиться к ней.

6. **ПЗ-006.** Найти `inf {(m²+5m+6)/(2m²+3m+4) : m∈ℕ}`.
7. **ПЗ-007.** Найти `inf {(m+2n+5)/(3m+2n+4) : m,n∈ℕ, m≥n}`.
8. **ПЗ-008.** Найти `inf {(2m+5)/(4n+3) : m,n∈ℕ, n≤m≤2n}`.
9. **ПЗ-009.** Найти `inf {(m²+4m+10)/(2m²+18m+21) : m∈ℕ}`.
10. **ПЗ-010.** Найти `inf {(3m+2n+4)/(7m+5n+8) : m,n∈ℕ, n≤m≤2n}`.

| ПЗ-006–ПЗ-010 | Нижние грани: зазор до инфимума и граничные значения | Рациональные выражения с натуральными параметрами |
