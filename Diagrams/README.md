# Реестр чертежей

Один файл — один чертёж. Имя на русском, по теме или примеру; устаревшие версии удаляются, а не копятся.

| Файл | Теорема | Числовой пример | Что показывает | Чего не доказывает |
|---|---|---|---|---|
| `следствие-9-логика-доказательства.svg` | Следствие 9° (плотность ℚ) | `a = 1,4`, `b = 2,1`, `n = 2`, `m = 3`, `r = 3/2` | Сетку с шагом `1/2`, `r` как первую отметку справа от `a`, отрезок длины `1/n` от `a` и цепочку `a < r ≤ a + 1/n < b` | Общий случай `a < b` — это иллюстрация одного примера, не доказательство |

## Правила

- Только SVG; PNG-копии не создаются.
- На чертеже подписаны все величины, точки и измеряемые отрезки, указан масштаб, если он важен.
- В ответе — ссылка на файл; в таблице — строка с теоремой и примером.
