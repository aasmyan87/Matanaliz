# Реестр чертежей

Один файл — один чертёж. Имя на русском, по теме или примеру; устаревшие версии удаляются, а не копятся.

| Файл | Теорема | Числовой пример | Что показывает | Чего не доказывает |
|---|---|---|---|---|
| `следствие-9-первая-отметка-справа-от-a.svg` | Следствие 9° (плотность ℚ), с. 81 | Сверху: `a = 1,4`, `b = 2,1`, `n = 2`, `m = 3`, `r = 3/2`. Снизу: `a = 1,4`, `b = 1,55`, `n = 8`, `m = 12`, `r = 1,5` | Почему опора на левый конец `a`: клетка `[(m−1)/n, m/n)` содержит `a`, её правый конец — первая отметка сетки справа от `a`, поэтому `r − a < 1/n`; сравнение полос `1/n` и `b − a`. Внизу — почему `m` именно наименьшее: следующая отметка `1,625` уже за `b` | Общий случай `a < b` — это два примера, а не доказательство; отдельно текстом оговорён случай `a` на сетке (знак `≤` слева) |

## Правила

- Только SVG; PNG-копии не создаются.
- На чертеже подписаны все величины, точки и измеряемые отрезки, указан масштаб, если он важен.
- В ответе — ссылка на файл; в таблице — строка с теоремой и примером.
