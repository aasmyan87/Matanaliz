# Реестр чертежей

Один файл — один чертёж. Имя на русском, по теме или примеру; устаревшие версии удаляются, а не копятся.

| Файл | Теорема | Числовой пример | Что показывает | Чего не доказывает |
|---|---|---|---|---|
| `следствие-9-логика-доказательства.svg` | Следствие 9° (плотность ℚ) | `a = 1,4`, `b = 2,1`, `n = 2`, `m = 3`, `r = 3/2` | Сетку с шагом `1/2`, `r` как первую отметку справа от `a`, отрезок длины `1/n` от `a` и цепочку `a < r ≤ a + 1/n < b` | Общий случай `a < b` — это иллюстрация одного примера, не доказательство |
| `принцип-архимеда-шаги-и-клетка.svg` | Принцип Архимеда (6°) | `h = 0,3`, `x = 2,0`, `k = 7` | Шесть полных шагов `h` от `0` до `1,8`, остаток `0,2`, клетку `[6h, 7h) = [1,8; 2,1)` и формулу `(7−1)·0,3 ≤ 2,0 < 7·0,3` | Общий случай `h > 0`, `x ∈ ℝ` — это иллюстрация одного примера, не доказательство |
| `пример-конечного-подпокрытия-борель-лебега.svg` | Лемма о конечном покрытии (Борель – Лебег), Зорич, т. 1, гл. II, § 3, п. 2 | `[0,1]`, `U_x = (x − 0,12; x + 0,12)`, шесть интервалов `U_0`, `U_{0,2}`, …, `U_{1,0}` | Из несчётного покрытия выбраны шесть интервалов; цветные куски оси показывают, какой интервал покрывает каждую часть `[0,1]` | Это иллюстрация одного покрытия, а не доказательство леммы; шесть — не обязательно минимальное число |

## Правила

- Только SVG; PNG-копии не создаются.
- На чертеже подписаны все величины, точки и измеряемые отрезки, указан масштаб, если он важен.
- В ответе — ссылка на файл; в таблице — строка с теоремой и примером.
