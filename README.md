# Матанализ по Зоричу

Учебный проект по математическому анализу: разборы доказательств, конспекты, чертежи и журнал занятий. Работа идёт в связке с ИИ-ассистентом, правила которого зафиксированы в [`AGENTS.md`](AGENTS.md).

## Принципы

- **Зорич — ось курса.** Формулировки, доказательства, обозначения и порядок изложения берутся у Зорича (т. 1–2). Всё остальное помогает понять именно его текст.
- **Веллеман — логика доказательства.** «Искусство доказательства в математике»: логическая форма цели и посылок, выбор стратегии, структура аргумента.
- **Фихтенгольц и Кудрявцев — вспомогательные.** К ним обращаются точечно, чтобы прояснить конкретное место Зорича (другая формулировка, пример, недостающий шаг). Их доказательства не пересказываются и не сравниваются с зоричевскими.
- **Вопросы бывают любыми.** Фрагмент задачи или текста из другого источника разбирается по существу с привлечением всех доступных ресурсов; свободная беседа на любую тему — тоже нормальный режим работы.

## Начало работы на новом компьютере

```
git clone https://github.com/aasmyan87/Matanaliz.git
cd Matanaliz
git config user.name "Ваше Имя"
git config user.email "ваш@email"
```

Затем скопируйте в корень проекта папку `Books/` — она не хранится в репозитории (см. раздел «Книги»).

Для работы скриптов из `tools/pdf` один раз установите зависимости:

```
pnpm --dir tools/pdf install
```

## Инструменты

Поиск фразы по книге (регистр не важен):

```
node tools/pdf/search.mjs "Books/Zorich MatAnaliz 1.pdf" "Архимеда"
```

Показать страницу целиком, метаданные или оглавление:

```
node tools/pdf/search.mjs "Books/Zorich MatAnaliz 1.pdf" --page 80
node tools/pdf/search.mjs "Books/Zorich MatAnaliz 1.pdf" --meta
node tools/pdf/search.mjs "Books/Zorich MatAnaliz 1.pdf" --outline
```

Отрендерить страницу скана в PNG (временный файл для просмотра):

```
node tools/pdf/render.mjs "Books/Курс дифференц. и интегр. исчисления. Т.1._Фихтенгольц_2003, 680с.pdf" 50 page.png 1.0
```

Проверить внешние ссылки из `links.md`:

```
node tools/check-links.mjs
```

Подробности — в [`tools/pdf/README.md`](tools/pdf/README.md).

## Чертежи

Каждый чертёж — отдельный SVG в `Diagrams/` с описательным именем на русском. Реестр [`Diagrams/README.md`](Diagrams/README.md) фиксирует, какую теорему иллюстрирует файл, на каком числовом примере, что показывает и чего не доказывает. PNG-копии в репозитории не хранятся.

## Книги

Папка `Books/` (16 файлов, ~71 МБ) намеренно исключена через `.gitignore`: это тяжёлые сканы и PDF, защищённые авторским правом. На новом компьютере её нужно скопировать отдельно (облако, флешка). Без неё проект работает, но поиск и сверка по страницам будут недоступны.
